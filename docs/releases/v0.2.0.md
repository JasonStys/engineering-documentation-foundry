# 0.2.0 native application

The original deterministic PDF pipeline and cited corpus comparator now have a real editable
desktop/browser application. Users upload actual PDFs, author source declarations and bounded
settings, save explicit revisions, run the original engine, search source-cited canonical content,
preview/download exact artifacts, compare actual saved builds and retain history after restart.
Complete project files include the original PDFs; imports create new identities and never adopt
supplied output reports. Conflicts and late asynchronous replies preserve current edits.

The native owner has Open/Browser/Help/Exit controls, fresh capability-bound loopback ownership and
normal accepted-work drain. Private workspace admission refuses existing aliases, hardlinks and
frozen program paths before mutation. This is a single trusted OS owner's plaintext workspace,
not a hosted account service, malicious-PDF sandbox or automatic technical approval system.

Native archives exclude PyMuPDF/fitz/MuPDF binaries. Explicit first-run Install/Cancel explains the
official pinned parser's AGPL/commercial terms before data access. Exact size, digest, ABI, RECORD,
bounded extraction and offline inventory/hash checks precede import. No pip/source build/global
dependency installation occurs at runtime. See [the setup boundary](../PDF_ENGINE_SETUP.md).

Original source tests, Python 3.11–3.13, strict types/lint, distribution builds, dependency audit and
the 90% coverage floor remain. Coverage now includes the new native source as well. Native CI
builds/safely extracts/uses all three supported OS families with patched Python 3.14.10, actual
Chromium journeys and no binary artifact uploads. CodeQL adds the editor language to existing
Python/Actions security-extended analysis without exclusions or ignored failures.

The [published Windows release](https://github.com/JasonStys/engineering-documentation-foundry/releases/tag/v0.2.0)
is bound to exact runtime source `fa0cf1a0132e56e2b0016207b3d5aecd08a29c2a`.
Its ZIP and sidecar were independently downloaded and verified. The actual installed application
passed real PDF authoring, publication, comparison and restart workflows with three normal exits,
four retained builds/two projects and all 114 installed files unchanged. A separate native Open,
Help and Exit inspection passed. Desktop and Start-menu targets were read back; ordinary
default-profile shortcut activation and OS browser opening were not independently exercised.
