## Installation and operating limits

Verify SHA256 and extract the complete Windows x64 ZIP. Keep all files and notices together. Open EngineeringDocumentationFoundry.exe or the Desktop icon; the native menu provides Open workspace, Browser, Help and Exit. A supported Microsoft Visual C++ runtime is required.

Initial setup separately downloads the pinned official PyMuPDF 1.28.2 wheel after explicit consent under GNU AGPL or Artifex commercial terms. The app bundles no parser and sends no documents to its provider. Workspace and exports are local plaintext; test profiles were isolated from normal data.

Text PDF and ruled-table heuristics have bounds; images remain placeholders. This is not OCR, universal file understanding, unit normalization, technical approval or a hostile-PDF sandbox. Inspect warnings and original source evidence.

One trusted OS owner; no hosted accounts or encryption. The unsigned Windows portable release is not a signed installer or clean-machine certification. Linux/macOS packages passed hosted tests but are not downloadable release assets here. Default-profile icon activation and the OS browser opener were not independently exercised.

Protect original PDFs, plaintext workspaces and exported project files. Read [PDF-engine setup](../PDF_ENGINE_SETUP.md) before accepting its separately downloaded dependency, and follow [the native application guide](../native-application.md) for exact source declarations, explicit saved revisions, immutable artifacts, backup and normal Exit. The cited comparator supports human review; changed or removed safety notices never become automatic technical approval.
