# Changelog

All notable changes are documented here.

## 0.2.0 - source/native candidate, 2026-11-11

- Added a real editable local application around the unchanged PDF build and cited revision engines.
- Added source upload/download, registry/settings authoring, explicit saved revisions, immutable
  build history, canonical search, sandboxed original preview and exact project/artifact exports.
- Added atomic complete project import, revision conflicts, captured asynchronous editing guards,
  explicit removal, honest capacity failures and restart retention.
- Added an owned native Open/Browser/Help/Exit window, fresh loopback authority, pre-mutation
  workspace path admission and accepted-work/child drain before normal exit.
- Added explicit official PyMuPDF first-run setup without bundled parser binaries or automatic
  licensing-clearance claims. Packaging uses a separate exact minimal runtime environment.
- Added meaningful source/native/browser/bootstrap regressions and three-OS extracted package CI;
  retained original source-version, strict typing/lint, audit, build and 90% coverage gates.
- Extended the existing security-extended CodeQL matrix to the real TypeScript/JavaScript editor.

Public release and installation remain later separately verified steps. Existing 0.1.0 source,
measurements and Office editions retain their historical identities.
