    Extraction settings and source identity

    max_pages: 1–100 per PDF; max_blocks_per_page: 1–5,000; heading_ratio: 1.05–3. These are limits, not silent truncation options. Exceeding a limit blocks that source.

    Keep the same source ID when revising a manual. Changing an ID appears as removal/addition in revision review. Expected SHA-256 is optional; actual uploaded bytes are always identified independently.

          6. 
        
        
        
        
          Supported inputs are text-based PDFs with ruled tables and complete
          exported project JSON. OCR and image/equation understanding are not
          provided. Image placeholders and heuristic headings require human
          review. Source units remain as written; this tool does not guess
          technical meaning or silently convert measurements.
        
        
        
        
          This is one trusted OS owner's local workspace, with plaintext SQLite
          data. It is not a hosted multiuser account service or a sandbox for
          hostile PDF exploits. No documents leave this machine. The only setup
          network request is the exact official parser dependency you explicitly
          approve; normal work is offline.
        
        
        
        
          Capacity is explicit: 120 library PDFs, 30 projects, 50 builds and 256
          MiB retained source/evidence bytes, excluding SQLite overhead. The app
          never prunes history. Export first, then explicitly remove selected
          records and unreferenced source PDFs. Close normally before copying
          the whole workspace for backup.
        
        
        
        
          Closing this browser leaves the native owner running. Use Quit
          application or the owner window's Exit; it stays open until accepted
          work and actual child processes finish.
